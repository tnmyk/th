Terminal Helper

A lightweight CLI tool to find and run the right commands. No googling, just ask.

~ $ th "search for TODO or FIXME in rust files, exclude target dir, show 2 lines context"
Command: grep -rnE "TODO|FIXME" --include="*.rs" --exclude-dir="target" -C 2 .
~ $

1. Install via curl

curl -fsSL https://th.tnmyk.workers.dev/install.sh | bash

2. Configure Gemini API Key

th --setup
